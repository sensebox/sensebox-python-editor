Measure temperature, humidity, pressure and gas resistance using the BME680.

## Initialise BME680

<!-- @slug bme680-initialisieren -->

Sets up the BME680.

```python
import board
import adafruit_bme680

i2c = board.I2C()
bme680 = adafruit_bme680.Adafruit_BME680_I2C(i2c, address=0x76)
```

## Measure air temperature

<!-- @slug bme680-lufttemperatur-messen -->

Reads air temperature in °C.

```python
temperature = bme680.temperature
print("Temperature: {:.2f} °C".format(temperature))
```

## Measure relative humidity

<!-- @slug bme680-luftfeuchtigkeit-messen -->

Reads relative humidity in %.

```python
humidity = bme680.relative_humidity
print("Humidity: {:.2f} %".format(humidity))
```

## Measure air pressure

<!-- @slug bme680-luftdruck-messen -->

Reads air pressure in hPa.

```python
pressure = bme680.pressure
print("Air pressure: {:.2f} hPa".format(pressure))
```

## Air quality: measure gas resistance

<!-- @slug bme680-gaswiderstand-messen -->

Reads gas resistance in ohms as a raw air-quality measurement.

```python
gas = bme680.gas
print("Gas resistance: {} ohms".format(gas))
```

## Estimate altitude from air pressure

<!-- @slug bme680-hoehe-schaetzen -->

Estimates altitude using air pressure and a reference value.

```python
bme680.sea_level_pressure = 1013.25
altitude = bme680.altitude
print("Altitude: {:.2f} m".format(altitude))
```

## Print all BME680 measurements regularly

<!-- @slug bme680-alle-messwerte-ausgeben -->

Sets up the sensor and prints readings and estimated altitude every two seconds.

```python
import time
import board
import adafruit_bme680

i2c = board.I2C()
bme680 = adafruit_bme680.Adafruit_BME680_I2C(i2c, address=0x76)
bme680.sea_level_pressure = 1013.25

while True:
    print("Temperature: {:.2f} °C".format(bme680.temperature))
    print("Humidity: {:.2f} %".format(bme680.relative_humidity))
    print("Air pressure: {:.2f} hPa".format(bme680.pressure))
    print("Gas resistance: {} ohms".format(bme680.gas))
    print("Altitude: {:.2f} m".format(bme680.altitude))
    time.sleep(1)
```
