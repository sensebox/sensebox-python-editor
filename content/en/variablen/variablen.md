Store and read values using a name.

## Create or set a variable

Stores or replaces the value of a variable.

```python
measurement = 23.5
measurement = 24.0
```

## Read a variable

Reads the stored value of a variable.

```python
measurement = 23.5
print(measurement)
```

## Set a data type

<!-- @alternatives Data type -->

Creates a value using the selected data type.

### Character

```python
character = "A"
```

### Text

```python
text = str("senseBox")
```

### Boolean

```python
active = bool(True)
```

### Number

```python
count = int(42)
```

### Large number

```python
large_number = int(2147483647)
```

### Decimal number

```python
temperature = float(23.5)
```
