Create, combine and print text.

## Text field

Stores text in a variable.

```python
text = "senseBox"
```

## Create text from

Combines text and numbers into text.

```python
temperature = 23.5
text = "Temperature: " + str(temperature) + " °C"
```

## Append text

Appends text to an existing text variable.

```python
text = "Hello"
text += " senseBox"
```

## Length

Returns the number of characters.

```python
text = "senseBox"
length = len(text)
```

## Is empty

Checks whether text is empty.

```python
text = ""
is_empty = len(text) == 0
```

## Print text

Prints text to the console.

```python
print("Hello senseBox!")
```

## Print values
