Der BME680 wird über I²C angeschlossen. Er erfasst Lufttemperatur, relative Luftfeuchtigkeit, Luftdruck und einen Gaswiderstand als Messgröße zur Luftqualität.

Füge zuerst **BME680 initialisieren** ein und ergänze danach die gewünschten Messblöcke. Alternativ kannst du das vollständige Beispiel **Alle BME680-Messwerte regelmäßig ausgeben** verwenden.

## BME680 initialisieren

<!-- @slug bme680-initialisieren -->

Verbinde den BME680 mit einem I²C-Anschluss der senseBox und initialisiere ihn einmal am Programmanfang:

```python
import board
import adafruit_bme680

i2c = board.I2C()
bme680 = adafruit_bme680.Adafruit_BME680_I2C(i2c, address=0x76)
```

<!-- @details -->

Dieses Beispiel verwendet die I²C-Adresse `0x76` aus dem bereitgestellten Code. Verwende dasselbe Objekt `bme680` für alle folgenden Messblöcke. Wenn dein Programm den I²C-Bus bereits als `i2c` eingerichtet hat, verwende ihn weiter und füge `i2c = board.I2C()` nicht erneut ein.

Die benötigte Bibliothek `adafruit_bme680` und ihre Abhängigkeit `adafruit_bus_device` werden beim Übertragen des Codes automatisch auf die senseBox geladen.

## Lufttemperatur messen

<!-- @slug bme680-lufttemperatur-messen -->

Lies nach der Initialisierung die Lufttemperatur in Grad Celsius aus:

```python
lufttemperatur = bme680.temperature
print("Lufttemperatur: %0.1f °C" % lufttemperatur)
```

## Relative Luftfeuchtigkeit messen

<!-- @slug bme680-luftfeuchtigkeit-messen -->

Lies nach der Initialisierung die relative Luftfeuchtigkeit in Prozent aus:

```python
luftfeuchtigkeit = bme680.relative_humidity
print("Relative Luftfeuchtigkeit: %0.1f %%" % luftfeuchtigkeit)
```

## Luftdruck messen

<!-- @slug bme680-luftdruck-messen -->

Lies nach der Initialisierung den Luftdruck in Hektopascal aus:

```python
luftdruck = bme680.pressure
print("Luftdruck: %0.3f hPa" % luftdruck)
```

## Luftqualität: Gaswiderstand messen

<!-- @slug bme680-gaswiderstand-messen -->

Lies nach der Initialisierung den Gaswiderstand in Ohm aus:

```python
gaswiderstand = bme680.gas
print("Gaswiderstand: %d Ohm" % gaswiderstand)
```

<!-- @details -->

Der Gaswiderstand ist ein Rohmesswert zur Untersuchung der Luftqualität. Der hier verwendete Treiber liefert damit keinen kalibrierten Luftqualitätsindex. Die Eigenschaft `gas` ist in der [Adafruit-Bibliotheksdokumentation](https://docs.circuitpython.org/projects/bme680/en/stable/api.html) beschrieben.

## Höhe aus dem Luftdruck schätzen

<!-- @slug bme680-hoehe-schaetzen -->

Optional kannst du nach der Initialisierung die Höhe über dem Meeresspiegel aus dem Luftdruck schätzen:

```python
# An den aktuellen Luftdruck auf Meereshöhe am Standort anpassen (hPa).
bme680.sea_level_pressure = 1013.25

hoehe = bme680.altitude
print("Geschätzte Höhe: %0.2f m" % hoehe)
```

<!-- @details -->

`1013.25 hPa` ist ein Standardwert. Für eine genauere Schätzung musst du den aktuellen, auf Meereshöhe bezogenen Luftdruck deiner Region eintragen. Die berechnete Höhe hängt von diesem Referenzwert und vom Wetter ab. Für die vier anderen Messwerte ist diese Einstellung nicht erforderlich.

## Alle BME680-Messwerte regelmäßig ausgeben

<!-- @slug bme680-alle-messwerte-ausgeben -->

Dieses vollständige Beispiel initialisiert den Sensor und gibt alle zwei Sekunden die Messwerte einschließlich der geschätzten Höhe aus. Es kann ohne die anderen BME680-Blöcke verwendet werden:

```python
import adafruit_bme680
import time
import board

# Sensor am Standard-I²C-Bus mit der Adresse 0x76 initialisieren.
i2c = board.I2C()
bme680 = adafruit_bme680.Adafruit_BME680_I2C(i2c, address=0x76)

# An den aktuellen Luftdruck auf Meereshöhe am Standort anpassen (hPa).
bme680.sea_level_pressure = 1013.25

while True:
    print("\nLufttemperatur: %0.1f °C" % bme680.temperature)
    print("Relative Luftfeuchtigkeit: %0.1f %%" % bme680.relative_humidity)
    print("Luftdruck: %0.3f hPa" % bme680.pressure)
    print("Gaswiderstand: %d Ohm" % bme680.gas)
    print("Geschätzte Höhe: %0.2f m" % bme680.altitude)
    time.sleep(2)
```

<!-- @details -->

Der Gaswiderstand ist kein kalibrierter Luftqualitätsindex. Die Höhe ist eine Schätzung und benötigt einen passenden Referenzluftdruck.

Mehr zur Ausgabe findest du unter [Ausgabe](doc:grundlagen/ausgabe), mehr zu Wiederholungen unter [Schleifen](doc:schleifen/schleifen). Die Messgrößen und Einheiten beschreibt die [Adafruit-Bibliotheksdokumentation](https://docs.circuitpython.org/projects/bme680/en/stable/api.html).
